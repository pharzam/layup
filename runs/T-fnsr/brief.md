# Problem statement: the demo target of M2a

This repository is the test target of the demo of milestone `M2a` of LAYUP
(task `T-fnsr`). It holds no product.

## The problem

The Operator wants to see that `layup run --new` makes the first records
commit of an empty GitHub repository as the LAYUP App's bot, and that a person
reads those records with a plain `git clone` and no tool.

## In scope

- One Start of this repository.

## Out of scope

- Intake, the Scaffold and any phase after Start.
