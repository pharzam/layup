Basis: libcurl under `git` reads `http_proxy`, `https_proxy`, `no_proxy` (and their upper-case forms), `SSL_CERT_FILE` and `SSL_CERT_DIR` from the environment; `git` reads `GIT_SSL_CAINFO`. The LAYUP host and `ubuntu-latest` need none of them, so no test shows it. A proxy URL can carry a credential (`http://user:password@proxy`), so the drop is in the spirit of K31, but the specification must say which it is: either name these variables as passed through (they change no branch, tree, hook, author or signature), or name their absence as part of the known limit `L-A7` with a "Close when" sentence. `note`.
