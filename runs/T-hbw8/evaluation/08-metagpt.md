## Verdict

**Reject as a component; borrow three patterns** (typed action output, the watch-table role routing, the budget stop with a correction). The PRD it writes has no requirement ID, no trace to the source sentence and no acceptance criterion. It fills gaps with its own assumptions instead of asking. At the pinned SHA the fixed-SOP Product Manager loops, and the default team skips the Product Manager on our PSB.

## What it is (from the code)

MetaGPT is a Python multi-agent framework. A `Team` holds roles in an `Environment`. The roles exchange `Message` objects. Each role runs `Action` objects. The CLI `metagpt "<idea>"` calls `generate_repo`.

All links below are at the pinned SHA. The prefix is `https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/`. The full URL is given for each citation.

- **The default team.** The CLI hires `TeamLeader`, `ProductManager`, `Architect`, `Engineer2` and `DataAnalyst` ([software_company.py#L44-L54](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/software_company.py#L44-L54)). `ProjectManager`, the classic `Engineer` and `QaEngineer` are commented out ([#L51-L62](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/software_company.py#L51-L62)). So the CLI options `--code-review`, `--run-tests` and `--implement` have no effect.
- **Two operating modes.** In "RoleZero" mode (the default) an LLM chooses the next command from a tool list, up to `max_react_loop = 50` steps ([role_zero.py#L71](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/di/role_zero.py#L71), [#L314-L335](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/di/role_zero.py#L314-L335)). The Team Leader sends work to a member by name, and an LLM picks the name ([team_leader.py#L75-L86](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/di/team_leader.py#L75-L86)). In "fixed SOP" mode (`use_fixed_sop=True`) each role subscribes to the action type that comes before it.
- **The SOP watch table.** `Role._watch` stores the action types a role reacts to ([role.py#L284-L288](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/role.py#L284-L288)). The Product Manager watches `UserRequirement` ([product_manager.py#L41-L47](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/product_manager.py#L41-L47)). The Architect watches `WritePRD` ([architect.py#L49-L52](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/architect.py#L49-L52)). The Project Manager watches `WriteDesign` ([project_manager.py#L40-L41](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/project_manager.py#L40-L41)). The Engineer watches `WriteTasks` ([engineer.py#L105-L106](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/engineer.py#L105-L106)).
- **Typed action output (ActionNode).** A node is a key, a Python type, an instruction and an example. `create_model_class` builds a pydantic model from the field map and rejects an output with a missing required field ([action_node.py#L247-L281](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/action_node.py#L247-L281)). `_aask_v1` parses the LLM text into that model and retries up to 6 times ([#L425-L452](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/action_node.py#L425-L452)). Modes for human review and revision exist ([#L665-L680](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/action_node.py#L665-L680)). The schema exists only in Python code. No schema file is written.
- **The PRD schema.** `WRITE_PRD_NODE` has 12 fields ([write_prd_an.py#L190-L220](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/write_prd_an.py#L190-L220)). "Requirement Pool" is a list of `[priority, text]` pairs, "top-5", priority P0/P1/P2 ([#L142-L147](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/write_prd_an.py#L142-L147)). When the requirement names no language, the default is "Vite, React, MUI, Tailwind CSS" ([#L19-L24](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/write_prd_an.py#L19-L24)). The design and task nodes have the same form ([design_api_an.py](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/design_api_an.py#L14-L87), [project_management_an.py](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/project_management_an.py#L13-L95)). No field links a design item or a task to a requirement.
- **Where the documents go.** `WritePRD` saves `docs/prd/<timestamp>.json` and a Markdown copy in `resources/prd/` ([write_prd.py#L218-L230](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/actions/write_prd.py#L218-L230)). ## What we ran

Work directory: `eval-work/metagpt/` (clone, venv, `home/`, `toy/`, `runs/`). The toy PSB is 15 lines. Line 8 ("must be fast on a large repository") is a metric with no measurement method. Line 9 ("stale TODOs") is an undefined term.

1. **Clone.** The full clone was too slow (56 MB after 6 minutes), so we stopped it and made a depth-1 clone: `git clone --depth 1 https://github.com/FoundationAgents/MetaGPT src`. HEAD is `11cdf466...`.
2. **Install.** `uv venv --python 3.11 .venv`, then `uv pip install -e src`. This **failed**: "there is no version of lancedb==0.4.0" on macOS arm64 (`requirements.txt:12`). We installed the requirements without `lancedb`, then `-e src --no-deps`. `metagpt --help` then **failed**: "TypeError: Secondary flag is not valid for non-boolean flag", because `typer==0.9.0` is pinned (`requirements.txt:9`) and click 8.5 was resolved. We pinned `click<8.2`. We also added `pyarrow`, because pandas failed to import without it. After these three fixes `metagpt --help` works.
3. **Config.** `HOME=home metagpt --init-config` wrote `home/.metagpt/config2.yaml` with `api_key: "YOUR_API_KEY"`. A placeholder key fails validation when the module is imported. We wrote a placeholder value and a small driver (`runs/driver.py`) that sets the key from the environment at run time. No key was written to a file. A search of all output files for the key values found nothing.
4. **Failed first calls (no cost).** `OPENAI_API_KEY` gave `401 invalid_api_key`. `gemini-2.5-flash` gave 404 ("no longer available"). `gemini-3.8-flash` and `gemini-3.5-flash` gave 503 ("high demand"). **In each of these runs the process exited with status 0** after the error (see I5).
5. **Run 1: fixed SOP team** (Product Manager, Architect, Project Manager, `use_fixed_sop=True`), budget USD 0.30, `n_round=6`, model `gemini-3.1-flash-lite`, input = the toy PSB.
   - `PrepareDocuments` took `project_path=todocount` from the PSB text (log: `prepare_documents:run:62 - project_path=todocount`). It made a new Git repository `runs/todocount/` relative to the working directory, not in the toy target.
   - The Product Manager wrote a PRD, then wrote it again every 8 to 20 seconds. After 10 minutes there were **49 PRD files** in `docs/prd/`. All 49 were the same (temperature 0, `llm_config.py:80`). The log then said `reached max_react_loop: 50` and `Bob(Architect): to do WriteDesign`. We stopped the process at that point. Cause: in SOP mode `_think` selects `WritePRD` again whenever the project path is a Git directory ([product_manager.py#L53-L64](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/product_manager.py#L53-L64)).
   - The cost log said `Total running cost: $0.000` for all 49 calls: `usage calculation failed: num_tokens_from_messages() is not implemented for model gemini-3.1-flash-lite`. So the USD 0.30 budget stop could not trigger.
   - `git log` of `runs/todocount` shows only `Add .gitignore`. The 49 PRDs were never committed, because the "Archive" commit runs only at the normal end.
6. **Run 2: default CLI team (MGX mode)**, budget USD 0.10, `n_round=5`, `stream=False` so that usage is counted. The Team Leader made one plan task and sent the whole task straight to the Engineer (`Alex`): "Please develop the 'todocount' CLI tool in Go ...". **It did not send it to the Product Manager or the Architect, so no PRD was made.** The Engineer's first step calls `Terminal.run_command("pwd")` ([engineer2.py#L57-L67](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/roles/di/engineer2.py#L57-L67)). That call hung. A 600-second alarm stopped the run. Cost reported: USD 0.001 (3 calls).
7. **Terminal test.** `Terminal().run_command('pwd')` alone also hung for 25 seconds, with a normal environment and with `env -i`. A traceback dump shows the loop waiting in `select`. The reader keeps the last complete line in a buffer until one more byte arrives, so the end marker line is not processed ([terminal.py#L156-L171](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/tools/libs/terminal.py#L156-L171)). This is our reading of the code; we did not test it on Linux.
8. **Unit tests without an LLM.** `pytest tests/metagpt/utils/test_cost_manager.py tests/metagpt/utils/test_git_repository.py tests/metagpt/actions/test_write_prd_an.py`: 6 passed, 1 error (the test needs `tests/data/rsp_cache.json`, a recorded LLM answer file).

**The PRD from run 1, compared with the toy PSB** (abridged):

```
"Requirement Pool": [["P0","Implement concurrent file scanning and TODO counting per package."],
  ["P0","Implement stale TODO detection logic using standard library."],
```

- The "fast" gap: not detected. The model joined line 8 with line 13 ("under 5 seconds") and made a P1 requirement.
- PSB lines 6 (zero-count packages not printed), 12 (no arguments) and 14 to 15 (out of scope) have no requirement. Lines 5 and 7 are joined into one entry.

## Invariants I1–I9

| Invariant | Effect | Reason |
| --------- | ------ | ------ |
| I1 Git is the system of record | conflicts | The configuration is in `~/.metagpt/`. The run state (`team.json`) goes to `workspace/storage`, outside the project ([const.py#L58](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/const.py#L58)). The cost stays in memory. Documents are committed only at a normal end: in run 1, 49 PRDs were not committed. |
| I2 The repository is independent | neutral | The output is plain files in a plain Git repository. The output needs no MetaGPT at run time. But MetaGPT writes no gates that could run without it. |
| I3 Agents cannot change rules | conflicts | Agents have an open shell and an open editor. No path is protected. |
| I4 No value without evidence | conflicts | The PM fills a gap with an assumption ("older than 6 months"). The LLM sets priorities. The stack defaults to React. |
| I5 An inactive check is not a pass | conflicts | A failed run exits with status 0 ([common.py#L675-L686](https://github.com/FoundationAgents/MetaGPT/blob/11cdf466d042aece04fc6cfd13b28e1a70341b1f/metagpt/utils/common.py#L675-L686)). We saw this after 401, 404 and 503 errors. When usage cannot be counted, the cost is 0 and the budget stop stays silent. |

## Limits of this evaluation

- We did not use an OpenAI model. The OpenAI key in the environment was invalid (401). We used `gemini-3.1-flash-lite` through an OpenAI-compatible endpoint. A stronger model can give a better PRD, but it cannot add fields that the schema does not have.
- We added a price entry for that model in the driver so that the budget could count. In run 1 the count still failed because the stream gave no usage. In run 2 we turned the stream off. The cost of run 1 is our estimate, not a measurement.
- We did not reach code generation, the Architect's design or the task list in a real run. Run 1 was stopped in the PM loop. Run 2 hung in the Terminal tool. We read the design and task schemas in the code only.
- We did not run incremental mode (`--inc`) against the toy target. In SOP mode it would loop in the PM, and in MGX mode it would hang in the Terminal. The target toy repository was not changed.
- We did not test the Terminal hang on Linux. The cause given is our reading of the code.
- We made a depth-1 clone, so we did not read the history. The full clone that the parent started for MetaGPT was stopped (see below).
- Mermaid CLI was not installed, so no diagram files were made. This does not change a rating.
- Processes: the full clone of MetaGPT (git clone and 2 git-remote-https processes) was stopped and replaced by a depth-1 clone. Run 1 was stopped with `pkill -f "driver.py sop"`. Run 2 and the two Terminal tests were stopped by their `alarm` timers. A final `ps` check found no MetaGPT or bash child process left.
