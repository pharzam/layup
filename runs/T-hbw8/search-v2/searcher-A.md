## What no verified candidate covers end-to-end

- S1 plus S6: batch all idea-owner questions before work, then obtain and accept routine answers from the correct role without asking a human. Springer escalates incomplete input; [Ask-or-Assume](https://github.com/nedwards99/Ask-or-Assume) queries a user, not a responsible role.
- S2, S3, S4, I4, I7, I8 **together**: pin Armature, cite evidence for every setting, prevent workers changing rules, and add stack-specific deterministic gates without weakening the baseline. sdlc-gh documents parts, not this combination.
- S7 and I5 **as specified**: all active layout, interface, contract and test-pyramid checks before a PR reaches human review, with separate identity for the actor that can change checks. Partial CI and code-owner protections do not prove the full gate set.
- S8: the PSB's precise authority rule (intent, batch PSB answers, named planned approvals, requirement acceptance, business-forking escalation, bounded stall referral) in one delivery system. A PR approval alone is not enough.
- S9: a bounded **stall** procedure with fresh independent examination, blind competing diagnoses when needed, and diagnosis plus outcome in the project repo. AgentJury documents blind completion review; it does not claim this stall workflow.
- S10: **mandatory** token count, latency and wall-clock duration per task in the **project repository**. GNAP's optional tokens and timestamps and other tools' dashboards do not prove this.
- S11: identifier, exact approved-PSB text trace, and acceptance criterion for **each** requirement. MetaGPT produces requirements; [Problem-Based SRS](https://github.com/RafaelGorski/Problem-Based-SRS) is a narrower traceability pattern.
- S12 and I1–I9 **together**: harness-neutral protected rules and project state in Git, independent reciprocal reviewer, enforced limits, and a project that still passes its own gates after removing orchestration. No shortlist README establishes that combination. LLM training and modifications to target cloud providers are outside this comparison.
