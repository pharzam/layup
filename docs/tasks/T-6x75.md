## Review round 1 and its fixes (cycle 1)

Review round 1 (GPT-6 Sol, effort `xhigh`, on the Devin CLI; `b31cc70`, cycle
0) gave `material`, with five material findings and two notes, all applied:

1. **A link to the baseline's repository itself** passed `kit-history`: the
   rule now reads the repository with no `/` after it, followed by the end of
   the text or a character that is not a letter, a digit, `-` or `_`.
2. **A `TMPDIR` in `WORK`** put the scratch tree in the work area: it is now an
   input error, before any tree. The first run of round 2, on `dba5ff0`, was
   stopped by the author after 30 s, before it wrote a record, because this fix
   failed for a relative `WORK`; the paths are now made absolute first.
3. **A failed add whose directory could not be removed** gave no cleanup
   error: it is now a `CleanupError` (exit 2).
4. **The harness did not check `pin OK` on `frame/bad-missing-linter`**, whose
   `EXPECT` has no line of `pin`: in a case of `frame`, a built check that
   `EXPECT` has no line of now gives `OK`.
5. **The scratch tree was added before the first step line:** it is now added
   in the step of the first built check and removed in the step of the last
   row, so the progress lines cover both. `layup gate` has the same silence; it
   is a known limit in `docs/spec/gate.md`, not a change of this task.

Notes 6 and 7: the count of the bad cases in the evidence, and the test that
the `PRD-0001` cell of `NFR-004` names for the exit code, are corrected.
